### ⚡ 2. AlgoForge — Interactive Algorithm Visualizer

**Tech Stack:** JavaScript | HTML5 | CSS3 | Data Structures & Algorithms

An interactive educational platform that demonstrates how sorting and pathfinding algorithms work through step-by-step animations and visual representations.

**✨ Key Features**
- Interactive sorting algorithm visualization
- Bubble Sort, Insertion Sort, Merge Sort, and Quick Sort
- Pathfinding visualization using BFS, DFS, Dijkstra, and A*
- Animated algorithm execution
- Adjustable animation speed
- Play, pause, reset, and step-by-step controls
- Interactive grid with customizable obstacles
- Algorithm performance tracking and comparisons
- Responsive dark-themed interface
- Automated algorithm tests using GitHub Actions
